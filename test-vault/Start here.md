# Try Chat Stream

Open **Weekend plan.canvas**. The left branch includes **Field notes**. The right branch is a separate question and excludes those notes.

1. Select the left question card. Run **Chat Stream: Preview context** in the command palette. You can do this before setting up a provider.
2. To generate a reply, install and enable **AI Providers**. In **Settings → AI Providers**, add a connection and choose a chat model. In **Settings → Chat Stream**, select the connection under **Provider**.
3. With the question card selected, run **Chat Stream: Generate AI note**. The reply appears as a purple card connected to the question.
4. Select the reply and run **Chat Stream: Create next note**. Type a follow-up and generate again, or select an earlier card to start another branch.
5. To assign your own shortcuts, search for Chat Stream in **Settings → Hotkeys**.

# Try Chat Stream

Open **Weekend plan.canvas**. The left branch includes the Field notes card. The right branch is a separate question and will exclude those notes.

1. Open **Settings → Chat Stream** to connect an AI provider. Previewing the example branches works before you link a key.
2. Select the left question card. Run **Chat Stream: Preview context** in the command palette to inspect the branch, then close the preview.
3. Run **Chat Stream: Generate AI note**. The reply appears below the question as a purple card with its own edge.
4. Select the reply and run **Chat Stream: Create next note**. Type a follow-up and generate again, or select an earlier question to fork the conversation.
5. In **Settings → Hotkeys**, search for Chat Stream and assign shortcuts if you prefer. Try Option+Shift+G and Option+Shift+N on macOS if those shortcuts are available.

Use **Test connection** before generating a live reply.
